# Duolingo 延续连胜自动化任务

<p class="lead">这份提示词用于操作本机已登录的 Chrome，在严格核对当日任务、控制课程数量并避开购买与账号设置的前提下，完成多邻国当天的三项每日任务。</p>

## 提示词简介

它把“延续连胜”约束为一个可核验的浏览器自动化流程：先读取当天三项任务及进度，再按当前课程顺序学习；每完成一课就复查任务，只做到三项全部完成为止。提示词还规定了答题、计时、跳过不可靠题型、异常中止与最终报告要求，避免凭经验猜测任务或在达标后继续操作。

### 适用情境

- 希望使用本机 Chrome 中已经登录的多邻国账号，自动完成当天全部三项每日任务。
- 需要根据每日任务的实时内容和进度动态决定课程数量，而不是沿用昨天的任务。
- 遇到“全对课程”或累计学习时长等任务时，需要明确、可复核的执行规则。
- 希望自动化过程不购买商品、不消耗宝石，也不修改账号、课程或学习语言设置。

::: tip 使用方式
复制下方完整提示词并发送给能够操作本机 Chrome 的智能体。开始前请保留需要使用的多邻国账号登录状态；若登录或页面验证受阻，智能体应停止并报告原因。
:::

```md
# Duolingo 延续连胜自动化任务

使用 Chrome 浏览器操作技能，在本机 Chrome 当前已登录的多邻国账号中完成今天的全部三个“每日任务”。

## 执行规则

1. 打开多邻国的“每日任务”页面，先读取今天三个任务的具体内容与当前进度，不要假设任务与昨天相同。
2. 根据任务要求，从当前课程进度继续往后学习并作答，直到三个每日任务全部完成。
3. 每完成一课，都返回或检查每日任务进度，再决定是否需要继续下一课；全部完成后立即停止，不要多做课程。
4. 尽量保证答案正确：
   - 仔细读取题目、选项、词序和大小写。
   - 提交前检查完整答案，尤其不要漏选主语、谓语或其他单词。
   - 如果任务要求“全对课程”，优先确保需要的课程无错题。
   - 如果答错，继续完成课程和错题订正，并根据任务进度补做课程，直到任务完成。
5. 遇到听力题、口语题或其他无法可靠完成的题型，直接点击“不方便听”“稍后再说”“跳过”或功能相同的按钮。不要猜测作答。
6. 如果任务要求累计学习一定时间，例如“学习 15 分钟”：
   - 进入任意一道普通题的作答页面。
   - 在该页面停留任务要求的完整时长。
   - 时间满足后再继续作答。
   - 不要通过反复刷新页面或进行无关操作计时。
7. 不要购买商品、消耗宝石、修改账号设置、切换课程或更改学习语言。
8. 如果 Chrome 中未登录、出现验证码、登录验证、网络故障或页面无法继续，停止操作并报告具体阻塞原因，不要尝试绕过。
9. 完成后打开“每日任务”页面，核实三个任务都已达到完成进度，再结束浏览器操作。
10. 最终报告：
    - 今天三个任务分别是什么；
    - 每项最终进度；
    - 完成了多少课；
    - 是否跳过了听力题或口语题；
    - 是否出现错题或其他异常。

只有在任务页面明确显示三个每日任务均已完成后，才可以报告成功。
```
