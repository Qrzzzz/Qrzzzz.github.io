# Duolingo 每日任务自动完成

<p class="lead">这份提示词让智能体使用内置浏览器读取 Duolingo 当天的三项每日任务，并以 <code>/quests</code> 的实时进度驱动后续学习。每完成一课就重新核验任务状态，直到全部完成或明确遇到阻塞。</p>

## 提示词简介

核心流程是一个简单的状态闭环：读取当天任务与进度，选择下一项必要课程，完成课程，再回到 `/quests` 重新判断。提示词同时覆盖未登录、身份验证、页面异常以及听力或口语题无法可靠完成等情况，恢复后仍以服务器显示的最新任务进度为准。

### 适用情境

- 希望使用智能体的内置浏览器完成当天三项 Duolingo 每日任务。
- 需要根据每日任务的实时内容和进度动态决定课程数量。
- 希望登录或身份验证中断后能够由用户接管，并在验证完成后继续执行。
- 需要以 `/quests` 的最终状态作为统一的完成判据。

::: tip 使用方式
复制下方完整提示词并发送给具备内置浏览器操作能力的智能体。若当前账号尚未登录，按提示在浏览器中完成登录后即可继续。
:::

```md
# Duolingo 每日任务自动完成

使用内置浏览器完成当前 Duolingo 账号今天显示的三个每日任务。

## 目标

打开：

https://www.duolingo.com/quests

读取今天三个每日任务的：

- 任务名称；
- 当前进度；
- 目标进度。

以 `/quests` 当前显示的状态作为完成情况的依据。

根据任务要求，从当前学习进度继续完成课程。每完成一课后重新检查 `/quests`，再决定下一步。

当三个任务均达到目标进度后立即结束。

## 登录

开始时检查当前账号状态。

如果尚未登录，打开 Duolingo 登录页面，并让用户直接在当前浏览器中完成登录。

如果执行过程中出现重新登录、验证码、双重验证或其他需要用户确认身份的页面，也让用户直接完成相应验证。

用户完成后，重新打开 `/quests`，重新读取三个任务及当前进度，再继续执行。

## 课程执行

根据尚未完成的每日任务选择接下来需要进行的课程。

正常从当前学习路径继续，不预先假定需要完成多少课。

每道题根据当前页面显示的题目、选项和词块作答，并在提交前检查答案是否完整。

如果答错，按照 Duolingo 提供的流程完成订正并继续课程。

对于无法可靠完成的听力、口语或类似题型，使用页面提供的跳过或暂不进行选项。

如果每日任务本身要求完成这类练习，则在课程结束后检查 `/quests` 是否实际累计了对应进度。如果持续无法获得所需进度，将该任务记为受阻。

如果任务要求累计学习时间，则通过正常完成课程累计，并在每课结束后检查任务进度。

## 状态验证

整个过程采用以下循环：

**读取 `/quests`  
→ 找出未完成任务  
→ 选择下一项必要课程  
→ 完成课程  
→ 返回 `/quests` 检查实时进度**

始终根据当前页面状态继续操作。

如果页面加载或交互出现异常，重新打开相关页面，并优先返回 `/quests` 确认当前进度。

恢复后根据最新状态继续，避免重复已经被服务器记录的课程。

如果浏览器、网络或身份验证问题持续导致任务无法继续，则结束执行并记录具体原因。

## 完成判定

结束前最后一次打开 `/quests`。

只有三个每日任务都明确达到目标进度时，最终状态才记为：

**成功**

如果只完成其中一部分，则记为：

**部分完成**

如果因为登录验证、页面故障、网络问题或无法完成必要题型而无法继续，则记为：

**受阻**

## 最终报告

报告：

- 今天三个每日任务的名称；
- 每项任务的最终进度；
- 实际完成的课程数量；
- 跳过的听力、口语或其他特殊题型数量；
- 错题及订正情况；
- 登录、页面或网络异常；
- 最终状态：成功、部分完成或受阻。
```
