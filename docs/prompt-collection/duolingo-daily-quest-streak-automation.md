# Duolingo 延续连胜自动化任务

<p class="lead">这份提示词用于操作本机已登录的 Chrome，在严格核对当日任务、控制课程数量并避开购买与账号设置的前提下，完成多邻国当天的三项每日任务；遇到浏览器控制异常时，它还会按“重新读取—重开标签页—重启 Chrome”的顺序恢复。</p>

## 提示词简介

它把“延续连胜”约束为一个可核验、可恢复的浏览器自动化流程：先读取当天三项任务及进度，再按当前课程顺序学习；每完成一课就复查任务，只做到三项全部完成为止。若 Chrome 控制超时或页面状态中断，智能体必须分级恢复，并在恢复后重新读取任务和课程状态，不能沿用旧 DOM、旧选择器或盲目重复操作。多日实测中，`GPT-5.6 Sol + medium` 是目前较可靠的最低运行配置，复杂或无人值守运行可考虑 `high`；这是经验基线而非绝对能力保证，模型与推理强度需要在运行任务时配置，无法由提示词本身强制设置。

### 适用情境

- 希望使用本机 Chrome 中已经登录的多邻国账号，自动完成当天全部三项每日任务。
- 需要根据每日任务的实时内容和进度动态决定课程数量，而不是沿用昨天的任务。
- 遇到“全对课程”或累计学习时长等任务时，需要明确、可复核的执行规则。
- 希望在 DOM 读取、选择器或 Chrome 控制会话异常时，按有限的恢复阶梯自助恢复，而不是首次超时就退出或无限重试。
- 希望自动化过程不购买商品、不消耗宝石，也不修改账号、课程或学习语言设置。

::: tip 使用方式
复制下方完整提示词并发送给能够操作本机 Chrome 的智能体。建议使用 GPT-5.6 Sol，推理强度至少为 `medium`。开始前请保留需要使用的多邻国账号登录状态；若登录、页面验证或 Chrome 插件连接受阻，智能体应按提示词限定的恢复阶梯处理，仍无法恢复时停止并报告原因。
:::

# Duolingo 延续连胜自动化任务

使用 Chrome 浏览器操作技能，在本机 Chrome 当前已登录的多邻国账号中完成今天显示的全部三个“每日任务”。

## 目标与完成标准

- 先打开 https://www.duolingo.com/quests，读取今天三个任务的名称和实时进度，不得沿用昨天的任务或旧页面状态。
- 根据当前任务，只完成必要的课程；每完成一课都重新检查 /quests。
- 只有 /quests 明确显示三个任务均达到目标进度时，才可以报告成功；全部完成后立即停止，不做额外课程。

## 作答规则

1. 从当前课程进度继续往后学习。每道题操作前读取当前可见页面；每次点击、提交或页面变化后重新读取，不使用旧 DOM、旧标签页 ID、旧题目状态或失效的选择器。
2. 仔细核对题目、选项、词序、大小写及全部词块。提交前确认答案完整，尤其不要遗漏主语、谓语或其他单词。
3. 若答错，完成应用提供的订正；随后以 /quests 的实时计数决定是否需要补做课程。不要自行假定正确率或 Combo Bonus 已计入。
4. 遇到无法可靠完成的普通听力题、口语题或类似题型，点击“不方便听”“稍后再说”“跳过”或等效按钮，不猜答案。
5. 如果每日任务本身要求听力或口语次数，而可用题型无法可靠完成、跳过后又不累计进度，则报告该任务受阻或部分完成，绝不伪报成功。
6. 如果任务要求累计学习时长，优先继续正常作答和完成课程，让时间自然累计；每课后复查进度。不得反复刷新或做无关操作来计时。
7. 遇到重复标签、重复词块或多个匹配元素时，先重新读取当前 DOM，并核对 locator 数量、可见性和 enabled/disabled 状态，再选择唯一的当前控件；不得依赖陈旧的宽泛文本或位置选择器。
8. 不购买商品、不消耗宝石、不进入付费或传奇挑战，不修改账号设置，不切换课程或学习语言。

## Chrome 故障恢复阶梯

1. 首次出现 Loading、DOM/selector 超时、页面空白或控制中断时，先等待片刻，只重新读取一次当前页面状态；不得盲目重复点击、重复提交答案或直接增加课程计数。
2. 如果再次失败，关闭当前多邻国标签页，新建标签页并重新打开 https://www.duolingo.com/quests。
3. 如果重开标签页后仍无法可靠操作，完全关闭 Chrome，再重新启动 Chrome，并打开 /quests。
4. 每次重新连接、重开标签页或重启 Chrome 后，必须先重新读取三个任务及当前进度，再检查当前课程/路径状态。中断前的操作可能已经被服务器记账；不得假设课程失败、不得直接重做课程。
5. 恢复后所有操作必须基于新 DOM 和实时页面状态，不复用旧 locator、旧题目状态或旧计数。
6. 如果重启 Chrome 后仍连续失败，或者出现未登录、验证码、登录验证、真实网络故障、Chrome 错误页、Chrome 插件/native host 不可用，则停止并准确报告阻塞原因；不得绕过验证、修复安全设置、切换到其他浏览器或无限重试。
7. 遥测或后台请求报错但页面仍能正常读取和操作时，可继续；只有主页面无法可靠读取或操作时才进入恢复阶梯。

## 最终报告

- 今天三个任务的名称；
- 每项最终进度；
- 实际完成课程数；
- 跳过的听力题或口语题数量（无法精确计数时明确说明）；
- 错题、订正、Chrome 恢复动作及其他异常；
- 明确结论：成功、部分完成或受阻。

只有实时 /quests 页面明确显示三个每日任务均已完成，才可报告成功。
