# 长篇 LaTeX PDF 一次成型生成器

<p class="lead">这份提示词用于让 AI 自主选择合适主题，并一次完成长篇中文文章写作、资料核验、LaTeX 排版、编译检查和 PDF 交付。</p>

## 提示词简介

它适用于需要生成独立 PDF 文档的场景，例如科普文章、知识手册、专题报告和长期保存的资料。提示词强调从选题开始建立完整生产流程：先选择具有可靠资料基础的主题，再完成结构化写作、引用检查、逻辑审查和 LaTeX 编译验证，减少“内容完成但无法交付”的情况。

### 适用情境

- 制作可独立阅读的中文科普 PDF。
- 将某个技术、历史、科学或社会议题整理成长文资料。
- 需要同时关注文章质量、引用可靠性和排版效果的文档生成任务。
- 需要输出 LaTeX 源文件并长期维护的出版式内容。

::: tip 使用方式
复制下方完整提示词即可使用。无需预先指定主题，模型会根据约束自行选择方向并完成完整文档。
:::

```md
请自行选择一个适合写成长篇中文 PDF 的主题，并一次性完成选题、标题设计、资料核验、文章写作、LaTeX 排版、编译检查和最终交付。

不要询问我选择什么主题，也不要设置后续复核阶段。最终结果应达到可以直接阅读和保存的成品状态。

主题可以来自自然科学、工程技术、数学、计算机、历史、科技史、城市研究、认知科学、环境科学等领域。优先选择资料可靠、结构清晰、能够自然展开成长文的方向。避免高度依赖实时信息、未经验证的争议话题或只能依靠个人观点成立的主题。

文章要求：

1. 自拟一个明确、有吸引力且符合正文内容的标题。
2. 正文不少于 6000 个汉字，避免通过重复内容增加篇幅。
3. 面向普通读者，但保持专业准确性和知识密度。
4. 按“背景 → 基础概念 → 核心机制 → 实际案例 → 局限与误解 → 总结”的逻辑组织文章。
5. 首次出现专业术语时解释其含义。
6. 必要公式必须解释变量、假设和实际意义。
7. 根据主题合理加入表格、时间轴、概念框、TikZ 示意图或其他辅助元素。
8. 不得虚构作者身份、个人经历、实验、调查或原创研究。

资料要求：

写作过程中必须自行完成事实核查。

涉及的年份、人物、机构、技术标准、实验结果、统计数据和因果关系必须检查准确性。

所有引用的论文、书籍、DOI、标准、报告和网页必须确认真实存在，并核对作者、标题、年份、出版信息以及是否真正支持正文中的对应观点。

优先使用政府机构、国际组织、大学、科研机构、标准组织和同行评审论文。

不得生成虚假的参考文献、DOI、链接或看似真实但无法验证的来源。

对于存在争议的研究，应根据证据强度使用谨慎表述，不得把相关性写成因果关系。

LaTeX 要求：

- 使用 ctexart 文档类。
- 使用 XeLaTeX 编译。
- 包含标题、摘要、目录、正文、结语和资料来源。
- 使用稳定常见宏包。
- 检查公式、表格、TikZ、交叉引用、参考文献和中文排版。
- 避免依赖不存在的本地文件或特殊字体。

最终交付前必须自行检查：

1. 标题和正文是否一致。
2. 全文逻辑是否连贯。
3. 是否存在事实错误、概念混淆或无依据结论。
4. 所有引用是否真实且匹配正文。
5. LaTeX 是否能够正常编译生成 PDF。
6. 删除重复、空泛和明显模板化内容。

最终只交付完整成品，不输出写作计划、待办事项或要求再次复核的说明。
```
