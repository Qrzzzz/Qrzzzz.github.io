# Brand assets

`github-invertocat.svg` is the unmodified `GitHub_Invertocat_Black.svg` from
[GitHub's official logo download](https://brand.github.com/GitHub_Logos.zip),
retrieved on 2026-10-21. It identifies links to the GitHub profile. CSS masks
preserve its proportions and display the mark in black or white.
