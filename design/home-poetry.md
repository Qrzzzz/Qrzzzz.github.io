# 首页诗句与入口

2026-10-08

首页采用左侧 Library / Projects、右侧大字号诗句的双区构图。按位置参考图，桌面入口移至左侧
上半部：Library 偏左上并旋转 -3°，Projects 偏右下并旋转 2°。细蓝色曲线从左上沿侧边落下，
再向底部舒展，保留拖拽回落。手机将诗句移至上方，两个入口在下方错位排列，曲线沿左边和底部展开，允许自然滚动。
保留现有导航、搜索、主题切换与 GitHub / Docs 链接。

`homePoems.json` 原样收录来源聊天 `01a115dd-fc6d-76f1-be71-c6d91ca84f25` 的 200 条原创作品：
中文 120 条、英文 80 条；短诗 120 条、微型散文 80 条。页面注明 Words by 6 Astra。
中文使用现有阅读衬线字体，英文使用 Newsreader，不引入外部字体服务。

首页从每首开始逐字输出计时，60 秒后逆向逐字撤回，清空后停 240ms，再播放下一首。
采用洗牌袋，一轮内不重复，跨轮避免相邻重复。加载页仍独立使用原来的 50 首及 30 秒周期。
蓝色下划线光标全文出现后闪三次再消失，保留轻微柔光。正文没有发光或淡入淡出。

Pause / Resume 暂停与继续；Next 先撤回再切换，连续点击不跳过多首。选择诗句文字时暂停，
取消选择后恢复，但不会取消手动暂停。后台停计时，恢复时补偿停留时间；离开首页销毁播放器。
减少动态效果时直接显示全文并按周期换篇。无 JavaScript 时保留完整静态诗句与所有内容入口。
